Code Inspector

A skill-based electrical code trainer for the zSpace stylus display. Students practise 20 skills by learning the procedures of an electrical occupation, inspecting 3D buildings, designing panels and looking up rules. They choose a region, which sets the rules, units, wire sizes and voltages. No rule book, rule number or credential is shown. Updated for the occupation, tutorial, progress and accessibility decisions of 2026-10-12.
